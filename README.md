# FishMania

![FishMania icon](icon.png)

**FishMania** is a fishing expansion mod for [tModLoader](https://tmodloader.net) (Terraria 1.4.4.9) that turns fishing into a full progression path.

## Content

- **100 new fish** across every biome and condition: forest, ocean, desert, snow, jungle, corruption, crimson, hallow, glowing mushroom, sky, caverns, lava, honey — plus night-only, rain and blood moon catches, and secret legendary fish announced by sonar
- **20 fishing rods**, from the humble Cactus Rod up to the Supreme Angler's Rod (lava fishing!)
- **15 baits**, from the Plump Worm up to the mighty Starworm
- **10 fishing accessories**, culminating in the Legendary Angler's Gear
- **3 fishing armor sets** — Apprentice Fisher (early game), Fisherman (hardmode) and Abyssal Diver (endgame) — with fishing set bonuses such as permanent Fishing, Sonar and Crate potion effects
- **3 fishing-themed vanity sets**: Sailor, Brass Diver and Fish Costume
- **6 biome fishing crates** with custom loot: Mushroom/Mycelium, Cavern/Deepstone and Honey/Royal Jelly
- **3 pets**: goldfish, pufferfish and axolotl
- **Fish dishes and fishing potions**, including the Depths Elixir (temporary lava fishing)

## Building

The mod is built with tModLoader's own toolchain:

```
dotnet tModLoader.dll -build <path-to-this-folder>
```

Or place the folder in `Documents/My Games/Terraria/tModLoader/ModSources` and use **Workshop → Develop Mods → Build + Reload** in game.

All sprites are generated procedurally (pixel-art generator with cel shading, selout outlines and vanilla-calibrated proportions). Armor equip sheets are derived from [tModLoader's ExampleMod](https://github.com/tModLoader/tModLoader) (MIT).
